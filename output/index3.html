Редирект с http на https для nginx

 Чт 09 октября 2014  —  azq

Как-то встала задача - редирект с http на https. Задача решается просто, просто добавлением нескольких строк в директиву location / {}

if ( $scheme = "http" ) {
 rewrite ^/(.*)$ https://$host/$1 permanent;
}

теперь при заходе на http://domain.com будет происходить редирект на https://domain.com

Решаем проблему:
Сначала останавливаем службу:

sudo /Library/StartupItems/MySQLCOM/MySQLCOM stop

Далее выполняем:

/usr/local/mysql/bin/mysqld_safe --skip-grant-tables

Всё началось с того, что мой друг, играющий в компьютерные игры, замучился с тормозами системы, вирусами и непонятно откуда взявшимися приложениями от mail.ru. Дружище как раз играл в Steam-игры. А к OC Windows у меня давно сложившееся негативное отношение...<!--more-->

**Итак, задача: установить Steam на Linux.**

Заход первый (совершенно неправильный):
---------------------------------------

Первым делом мы начали гуглить и выяснили, что SteamOS основана на Debian. Кроме того узналось, что есть установщик для винды, который не работал. Я даже не удивился)

Так как на компе было 4ГБ оперативной памяти, решили не усложнять себе жизнь и поставить Debian8 32bit.

Далее поставили Steam, который просто не запускался(

Заход второй (неправильный):
----------------------------

Понятное дело поставили Debian8 64bit и понеслось:

-   Добавили "non-free" репозиторий в `/etc/apt/sources.list`</tt>

```
deb http://http.debian.net/debian/ jessie main contrib non-free
```

-   Включили [Multi-Arch](https://wiki.debian.org/ru/Multiarch/HOWTO), обновили список пакетов и установили Steam:

```
dpkg --add-architecture i386
aptitude update
aptitude install steam
```

"О, круто!" - подумалось нам, - "Steam запускается, игрушки качаются". **НО** тяжёлые игры не запускались.

**Вывод: нужны драйвера на видео-карту.**

-   Ок, устанавливаем видео-дрова.

```
aptitude install libgl1-nvidia-glx:i386
```

И всё!!! Система начала сносить добрую часть x64-приложений, а апогеем стала не рабочая видео-система, ну и, конечно, GNOME не запускался...

**Вывод:** **битность системы тому виной**, в частности:

```
dpkg --add-architecture i386
```

Третий заход (почти правильный):
--------------------------------

После 15-ой попытки решить проблему с помощью перебора всех возможных вариантов Debain 7/8 - i386/x64 и скачавания дров с оф.сайтов, родилась мысль поставить Ubuntu. Взяли для верности Ubuntu 16.04 i386.

Поставили, сразу для верности поставили драйвера

```
sudo apt-get update && sudo apt-get install nvidia-304 nvidia-settings
sudo nvidia-xconfig
```

Всё ок.

Поставили Steam, скачав официальный deb-пакет у сайта, но почти та же история - тяжёлые игрушки запускались с "битыми" текстурами. Плюс система висла на каждом шагу.

Глянув, наконец, системные требования к играм увидели - **x64**

Четвёртый заход (правильный):
-----------------------------

Тут, наконец-то, всё просто.

-   Устанавливаем Ubuntu 16.04 x64.
-   Качаем Steam с оф.сайта, устанавливаем через "Установка пакетов"
-   Устанавливаем дрова

```
sudo apt-get update && sudo apt-get install nvidia-304 nvidia-settings
sudo nvidia-xconfig
```

либо, можно скачать установщик с сайта NVIDIA.
